## How I Work

My approach follows a simple process:

1. Understand how the organisation currently works
2. Map the workflow and identify bottlenecks
3. Select one focused process to improve
4. Design and build a practical pilot
5. Test the system with users
6. Improve and expand it based on real needs

The objective is not to add more software for staff to manage.

The objective is to reduce friction, improve visibility, and make responsibility clearer.

## Responsible AI

I use AI as a supporting part of a workflow, not as an automatic replacement for professional judgement.

AI-assisted features should:

- Perform narrow and clearly defined tasks
- Produce drafts rather than unquestioned decisions
- Remain subject to human review
- Preserve user work when generation fails
- Communicate limitations clearly
- Avoid unnecessary exposure of sensitive information
- Improve the complete workflow, not merely generate text quickly
